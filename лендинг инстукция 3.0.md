## 1. ФУНДАМЕНТ, ФИЛОСОФИЯ И ZERO-FRAMEWORK СТЕК

Главная системная ошибка большинства агентств и веб-мастеров — разработка сервисных локальных сайтов на базе React, Next.js, тяжелых конструкторов (WordPress + Elementor) или Webflow.
Для американского сервисного бизнеса это оборачивается катастрофой:
* **Задержка отклика (FID/INP)**: Тяжелая JS-гидратация заставляет пользователя на смартфонах ждать 2–4 секунды перед тем, как клик по кнопке сработает. В США это приводит к немедленному уходу 40% рекламного трафика.
* **Ежемесячные издержки (SaaS Drain)**: Заказчик вынужден ежемесячно отдавать $29–$59 за подписку на конструктор или сервер Vercel/VPS, а также $15–$30 за сторонние виджеты отправки форм (Formspree, Typeform).
* **«Устаревание зависимостей»**: Спустя 6–12 месяцев проект на фреймворке невозможно обновить или пересобрать из-за конфликтов `npm dependencies`.

### Наш стандарт — Zero-Framework / Zero-Dependency Runtime:
1. **HTML5**: 100% валидный семантический код (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
2. **Vanilla CSS3**: Полная дизайн-система на CSS Custom Properties (`:root`), аппаратное ускорение сложных переходов (`transform: translate3d`, `will-change`, `opacity`), zero-runtime затраты.
3. **Vanilla JavaScript (ES6+)**: Модульная архитектура (`app.js`, `quotelock.js`, `translations.js`), 0 внешних JS-библиотек в рантайме.
4. **Serverless Backend (0$ в месяц)**: Вечный вебхук на Google Apps Script, развернутый на глобальных серверах Google.
5. **Глобальный CDN хостинг**: Firebase Hosting (HTTP/2, автоматический бесплатный SSL, задержка TTFB < 40 мс по всей территории США).

### Ключевые показатели боевого проекта:
* **Google PageSpeed / Lighthouse**: 96–100 во всех четырех категориях (Performance, Accessibility, Best Practices, SEO).
* **FCP (First Contentful Paint)**: < 0.6 секунды.
* **LCP (Largest Contentful Paint)**: < 1.0 секунды.
* **CLS (Cumulative Layout Shift)**: 0.000.

## 5. СТРОГАЯ ИНЛАЙН-ВАЛИДАЦИЯ ФОРМ: ПОЛНЫЙ ОТКАЗ ОТ NATIVE ALERT()

**КРИТИЧЕСКИЙ СТАНДАРТ КАЧЕСТВА**: Всплывающие системные окна браузера `alert("Please fill your phone")` выглядят как дешевый студенческий скрипт и вызывают отторжение у американских пользователей.

### Архитектура премиальной инлайн-валидации:
1. При попытке отправки пустой или некорректно заполненной формы:
   - Проблемное поле ввода получает класс ошибки `.error` (красная рамка и мягкое свечение).
   - Запускается микро-анимация потряхивания (CSS shake).
   - Прямо под полем появляется стилизованный блок с понятным текстом ошибки (`.ql-field-error-msg.visible`).
   - Страница **плавно скроллит экран к первому ошибочному полю** и устанавливает в него фокус ввода (`field.focus()`).
2. При начале ввода символов клиентом (событие `input`):
   - Класс `.error` моментально снимается.
   - Текст ошибки скрывается.
3. Автоматическая маска ввода телефонного номера США: ввод чистых цифр автоматически форматируется в стандарт `(XXX) XXX-XXXX`.

### Готовый эталонный код валидации (из боевого `quotelock.js`):
```javascript
// Автоматическая маска телефона США: (XXX) XXX-XXXX
const phoneInput = document.getElementById('ql-input-phone');
if (phoneInput) {
  phoneInput.addEventListener('input', (e) => {
    let x = e.target.value.replace(/\D/g, '').match(/(\d{0,3})(\d{0,3})(\d{0,4})/);
    if (x) {
      e.target.value = !x[2] ? x[1] : '(' + x[1] + ') ' + x[2] + (x[3] ? '-' + x[3] : '');
    }
  });
}

// Валидация перед отправкой бронирования
function validateAndSubmit() {
  const nameInput = document.getElementById('ql-input-name');
  const phoneInput = document.getElementById('ql-input-phone');
  const emailInput = document.getElementById('ql-input-email');
  const errName = document.getElementById('ql-err-name');
  const errPhone = document.getElementById('ql-err-phone');

  let hasError = false;
  let firstErrorField = null;

  // 1. Проверка имени
  if (!nameInput.value.trim()) {
    nameInput.classList.add('error');
    errName.textContent = 'Please enter your full name.';
    errName.classList.add('visible');
    hasError = true;
    if (!firstErrorField) firstErrorField = nameInput;
  }

  // 2. Проверка телефона США (минимум 10 цифр)
  const digits = phoneInput.value.replace(/\D/g, '');
  if (!phoneInput.value.trim() || digits.length < 10) {
    phoneInput.classList.add('error');
    errPhone.textContent = 'Please enter a valid 10-digit US phone number.';
    errPhone.classList.add('visible');
    hasError = true;
    if (!firstErrorField) firstErrorField = phoneInput;
  }

  // Скролл к первому ошибочному полю
  if (hasError) {
    firstErrorField.scrollIntoView({ behavior: 'smooth', block: 'center' });
    firstErrorField.focus();
    return false;
  }

  // Если всё заполнено верно — отправляем данные
  sendBookingToServer();
}
```

## 6. МУЛЬТИЯЗЫЧНОСТЬ НА 4 ЯЗЫКА (EN / ES / PT / RU) БЕЗ ПЕРЕЗАГРУЗКИ

В сервисных отраслях США (строительство, кровельные работы, детейлинг) испанский язык (ES) и португальский (PT) обеспечивают от 25% до 40% дополнительных коммерческих обращений.
Мы реализуем мгновенный перевод всех элементов интерфейса **на клиенте без перезагрузки страницы**.

### Архитектура модуля `translations.js`:
1. **Словарь переводов**: Единый объект `MIRACULOUS_TRANSLATIONS` с ключами по разделам (`hero.title`, `calc.sizeSedan`, `pkg.gold.desc`).
2. **Селекторы в DOM**:
   - Для текста: атрибут `data-i18n="ключ"`.
   - Для placeholder в полях ввода: атрибут `data-i18n-ph="ключ"`.
3. **Автоопределение языка**:
   - При первом визите язык берется из `navigator.languages[0] || navigator.language`. Если язык начинается с `es`, автоматически включается испанский, если `pt` — португальский.
4. **Сохранение выбора**: Выбранный пользователем язык сохраняется в `localStorage.setItem('user_lang', lang)`.
5. **UI-переключатели**:
   - **Десктоп**: Стеклянный выпадающий список (Glassmorphic Dropdown) в шапке с кодами языков и иконкой глобуса.
   - **Мобильные**: Сегментированная горизонтальная плашка `[ EN ] [ ES ] [ PT ] [ RU ]` в верхней части полноэкранного мобильного меню.

## 7. МОБИЛЬНАЯ ЭРГОНОМИКА: 100DVH МЕНЮ, SCROLL-LOCK И ФИКС МОБИЛЬНОГО ЛОГОТИПА

Более 78% американского сервисного трафика приходит со смартфонов (в особенности iPhone на Safari). Ошибки верстки на мобильных моментально убивают продажи.

### 1. Полноэкранное меню 100dvh и блокировка фонового скролла:
При открытии меню гамбургера задний фон страницы **обязан намертво блокироваться**, чтобы свайпы пальцем внутри меню не прокручивали сайт под ним.
* Сохраняем текущую позицию скролла: `savedScrollPosition = window.pageYOffset;`
* Добавляем класс `.menu-open` на `html` и `body`.
* Фиксируем body через `document.body.style.top = -savedScrollPosition + 'px'`.
* Скрываем нижнюю фиксированную плашку `sticky-mobile-bar`, чтобы она не перекрывала пункты меню.
* При закрытии возвращаем скролл: `window.scrollTo(0, savedScrollPosition)`.

```css
/* Жесткая блокировка фонового скролла */
html.menu-open,
body.menu-open {
  overflow: hidden !important;
  height: 100% !important;
  width: 100% !important;
  touch-action: none !important;
  -webkit-overflow-scrolling: auto !important;
}

body.menu-open {
  position: fixed !important;
}
```

### 2. Фикс видимости логотипа на смартфонах:
Частая ошибка начинающих верстальщиков — скрывать изображение логотипа на мобильных через `display: none !important;`. Логотип обязан аккуратно отображаться в шапке:
```css
@media (max-width: 768px) {
  .brand-logo-img {
    display: inline-block !important;
    max-height: 18px !important;
    width: auto !important;
    margin-right: 8px !important;
  }
}
```

### 3. Защита от авто-зума на iOS Safari:
Если поле `<input>`, `<select>` или `<textarea>` имеет размер шрифта меньше 16px, мобильный Safari при тапе приближает экран («зумит»), ломая адаптивную верстку.
* **Правило**: Все поля ввода на мобильных экранах строго имеют `font-size: 16px !important;`.

### 4. Поддержка Home Bar (Safe Area Inset):
Нижняя плашка для мобильных обязана учитывать полоску Home Bar на iPhone:
```css
.sticky-mobile-bar {
  padding-bottom: calc(14px + env(safe-area-inset-bottom, 0px));
}
```

## 9. OPEN GRAPH & SOCIAL MEDIA PREVIEW: ПРОЦЕДУРНАЯ ГЕНЕРАЦИЯ КАРТОЧКИ 1200x630

Когда клиент или маркетолог отправляет ссылку на сайт в мессенджерах (iMessage, WhatsApp, Telegram, Facebook), превью решает всё. Случайный скриншот или размытое лого выглядят любительски.
Мы создаем **процедурную эталонную OG-карточку размером ровно 1200x630px** с помощью скрипта на Python PIL.

### Анатомия продающей OG-карточки:
* **Фоновый паттерн соты/карбона (Honeycomb)** для передачи ощущения премиального детейлинг-бокса.
* **Центральное радиальное неоновое свечение (Radial Bloom)** позади главного объекта.
* **Вырезанный силуэт автомобиля / объекта** с многослойным неоновым контуром (Fuchsia Halo).
* **Векторные золотые звезды `★ ★ ★ ★ ★ 5.0 RATED`**.
* **Информационные бейджи**: подтвержденная лицензия и страховка, телефон компании, город и штат.
* **УТП крупным шрифтом**: `"CERAMIC COATING & PAINT CORRECTION | VANCOUVER, WA"`.

### Готовый скрипт генерации (`tools/create_og_preview.py`):
```python
import math
import os
from PIL import Image, ImageDraw, ImageFilter, ImageFont

def draw_hexagon(draw, center_x, center_y, size, outline_color, width=1):
    points = []
    for i in range(6):
        angle = math.radians(60 * i + 30)
        x = center_x + size * math.cos(angle)
        y = center_y + size * math.sin(angle)
        points.append((x, y))
    draw.polygon(points, outline=outline_color, width=width)

def draw_star(draw, cx, cy, r_outer=6.5, r_inner=3.0, fill_color=(251, 191, 36, 255)):
    points = []
    for i in range(10):
        r = r_outer if (i % 2 == 0) else r_inner
        angle = math.radians(i * 36 - 90)
        x = cx + r * math.cos(angle)
        y = cy + r * math.sin(angle)
        points.append((x, y))
    draw.polygon(points, fill=fill_color)

def generate_og_image(output_path="assets/images/og-preview.jpg"):
    W, H = 1200, 630
    bg = Image.new("RGBA", (W, H), (8, 9, 13, 255))
    
    # 1. Сетка сот
    honeycomb = Image.new("RGBA", (W, H), (0, 0, 0, 0))
    hdraw = ImageDraw.Draw(honeycomb)
    hex_size = 38
    h_spacing = hex_size * math.sqrt(3)
    v_spacing = hex_size * 1.5
    
    col = 0
    x_start = -hex_size
    while x_start < W + hex_size * 2:
        y_start = -hex_size
        while y_start < H + hex_size * 2:
            cx = x_start
            cy = y_start + (h_spacing / 2 if (col % 2 == 1) else 0)
            draw_hexagon(hdraw, cx, cy, hex_size - 4, (255, 255, 255, 12), width=1)
            y_start += h_spacing
        x_start += v_spacing
        col += 1
    bg = Image.alpha_composite(bg, honeycomb)
    
    # 2. Неоновое свечение позади объекта
    glow = Image.new("RGBA", (W, H), (0, 0, 0, 0))
    gdraw = ImageDraw.Draw(glow)
    for r in range(480, 0, -8):
        frac = 1.0 - (r / 480)
        alpha = int(120 * (frac ** 1.6))
        bbox = [W // 2 - r, 210 - int(r * 0.65), W // 2 + r, 210 + int(r * 0.65)]
        gdraw.ellipse(bbox, fill=(189, 55, 130, alpha))
    glow = glow.filter(ImageFilter.GaussianBlur(28))
    bg = Image.alpha_composite(bg, glow)

    # 3. Наложение силуэта объекта с неоновым ореолом
    car_path = "assets/images/logo-car.png"
    if os.path.exists(car_path):
        car_img = Image.open(car_path).convert("RGBA")
        target_w = 680
        target_h = int(car_img.size[1] * (target_w / car_img.size[0]))
        car_resized = car_img.resize((target_w, target_h), Image.Resampling.LANCZOS)
        mask = car_resized.split()[3]
        
        # Размытый контур свечения
        halo = Image.new("RGBA", (W, H), (0, 0, 0, 0))
        halo_c = Image.new("RGBA", (target_w, target_h), (217, 70, 239, 255))
        halo_c.putalpha(mask)
        paste_x = (W - target_w) // 2
        paste_y = 100
        halo.paste(halo_c, (paste_x, paste_y), halo_c)
        halo = halo.filter(ImageFilter.GaussianBlur(20))
        bg = Image.alpha_composite(bg, halo)
        bg.paste(car_resized, (paste_x, paste_y), car_resized)

    # 4. Тексты, звезды и бейджи
    draw = ImageDraw.Draw(bg)
    font_title = ImageFont.truetype("arialbd.ttf", 38)
    font_sub = ImageFont.truetype("arialbd.ttf", 18)
    
    # 5 звезд рейтинга
    star_x_start = W // 2 - 140
    for i in range(5):
        draw_star(draw, star_x_start + i * 28, 385, 9, 4.5)
    draw.text((star_x_start + 155, 376), "5.0 GOOGLE RATED", fill=(255, 255, 255, 255), font=font_sub)

    # Главный заголовок
    draw.text((W // 2, 440), "CERAMIC COATING & PAINT CORRECTION", fill=(255, 255, 255, 255), font=font_title, anchor="mm")
    draw.text((W // 2, 485), "VANCOUVER & CAMAS, WA • OVER 20 YEARS MASTERY", fill=(240, 171, 252, 255), font=font_sub, anchor="mm")

    # Конвертация и сохранение
    bg.convert("RGB").save(output_path, "JPEG", quality=95)
    print(f"✅ Generated {output_path}")

if __name__ == "__main__":
    generate_og_image()
```
